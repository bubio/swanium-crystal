# 機能対応表

## 製品境界

Swanium Crystal は Rust 版 Swanium を参照実装とする Crystal 製品であり、エミュレーションの互換性は同等を目標とする。製品上の意図的な差分は、**SwanCrystal 固定**でローカルのカートリッジを直接起動し、実 BIOS、その選択 UI、BIOS 起動フローを扱わないことだけである。Mono / WonderSwan Color 用 ROM は SwanCrystal の後方互換として実行する。

この表では、Rust 版との差分を製品境界に照らして扱う。`対象外` は上記の意図的な非対応だけ、`要実装` は Rust 版との同等性に必要な未移植機能である。

## コアとカートリッジ

| 領域 | Rust 版の参照機能 | SwanCrystal の方針 | 現状 | 根拠・次の判断 |
| --- | --- | --- | --- | --- |
| 実行機種 | Mono / Color / Crystal を選択 | Crystal 固定。旧機種 ROM は後方互換で実行 | 対応 | `WonderSwanBus.from_cartridge` は常に `Crystal` を選ぶ。 |
| 実 BIOS | BIOS 選択・起動、内部 EEPROM | 対象外 | 対象外 | カートリッジのリセットベクタから直接起動する。BIOS ファイル・設定・UI を追加しない。 |
| V30 CPU | 命令実行、割込み、I/O | 対象 | 対応 | Crystal spec と WSCpuTest ハーネスで継続検証する。 |
| 基本メモリ・I/O | WRAM、入力、割込み、タイマ、カートリッジ窓 | 対象 | 対応 | 市販タイトルと自作 fixture の回帰対象。 |
| Bandai 2001 mapper | 標準バンク切替 | 対象 | 対応 | C0--C3 レジスタを実装済み。 |
| Bandai 2003 mapper | 拡張バンク切替 | 要実装 | 未対応 | ヘッダは読むが D0--D5 と拡張バンク解決を実装していない。対応タイトルを保証する前に実装・spec化する。 |
| SRAM / カートリッジ EEPROM | ゲームセーブ媒体 | 対象 | 対応 | 専用保存先への永続化を実装済み。 |
| カートリッジ RTC | RTC フッタ・時計プロトコル | 対象 | 対応 | RTC フッタ、0xCA / 0xCB プロトコル、決定論的な時刻進行、セーブステートを実装・spec化済み。Rust版と同じくSRAM/EEPROMの生保存データには含めない。 |
| GDMA | Color 系の転送 | 対象 | 対応 | 同期転送と CPU 待機サイクルを実装済み。 |
| SDMA | WSC の音声 DMA | 要実装 | 未対応 | 0x4A--0x52 のレジスタ値は保持するが、転送エンジンはない。SDMA 使用タイトルを保証する前に実装・spec化する。 |

## 映像・音声・フロントエンド

| 領域 | SwanCrystal の方針 | 現状 | 根拠・次の判断 |
| --- | --- | --- | --- |
| PPU | Crystal の Color 拡張を対象にする | 対応 | 2bpp / planar・packed 4bpp、背景、スプライト、縦画面、RGBA 出力を fixture で検証する。 |
| APU 基本音源 | 波形、ノイズ、スイープ、PCM、HyperVoice を対象にする | 対応 | 自作 PCM fixture と市販タイトル確認を継続する。 |
| PCM SDMA 給電 | SDMA の一部として扱う | 要実装 | SDMA 行の完了条件に含める。 |
| SDL2 | macOS の表示、入力、音声出力 | 対応 | 固定倍率、ゲームパッド、音声キュー、縦画面を提供する。 |
| UI / ライブラリ管理 | 明示指定 CLI とデバッグオーバーレイのみ | 対象外 | ROM 一覧、収集、ダウンロード、BIOS 選択 UI は追加しない。 |
| セーブステート | Crystal 固定状態の保存・復元 | 対応 | バージョン付き独自形式。新規デバイス追加時は状態も拡張する。 |

## 検証の基準

1. 通常 CI は自作 fixture、`crystal spec`、リリースビルド、SDL dummy 起動を実行する。
2. Rust 版のユニットテスト、統合テスト、採用済み公開 ROM は、実 BIOS と機種選択だけを除き、同じ入力・合否オラクルで Crystal 側へ移植する。テスト数の一致ではなく、機能とケースの対応で完了を判定する。
3. 市販タイトルを互換性表へ追加する前に、そのタイトルが使う mapper、DMA、RTC をこの表で `対応` と確認する。`要実装` の機能を使うタイトルは「動作確認済み」には記録しない。
4. 実 BIOS を必要とする再現手順は対象外として記録し、直接起動との差分修正の根拠にはしない。
