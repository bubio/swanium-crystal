# 互換性

最初の動作保証対象は macOS である。Linux、Windows、その他のプラットフォームは、macOS の市販ゲーム互換性が安定してから検証・配布対象に加える。

## 記録方針

市販ゲームの互換性は、利用者が合法的に保持するローカル ROM を macOS 実機で確認して記録する。ROM 本体、ハッシュ、セーブデータ、スクリーンショットはリポジトリや CI に含めない。

各タイトルでは、タイトル名、検証した版、確認日、macOS の機種、起動、入力、映像、音声、セーブ、一定時間の連続実行、既知の制限を記録する。互換性の問題は可能な限りハードウェア機能と再現手順に結び付け、自作 fixture または公開テスト ROM の回帰テストへ還元する。
