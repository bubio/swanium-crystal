# アーキテクチャ

`Swanium::Core` はエミュレーション状態を保持し、同期的な実行APIを公開する。`Machine` はCPUとLCDの159走査線タイミングを進め、`Ppu` は224×144のRGB444内部画面と、固定長のRGBA8888フレームバッファAPIを提供する。ここには SDL2、OS API、ファイル I/O、壁時計を持ち込まない。

`Swanium::Platform` は OS 依存の実装を隔離する。`Swanium::Platform::Sdl` はSDL2初期化、ウィンドウ、ストリーミングテクスチャ、整数倍率表示、60 Hz提示、キーボード／ゲームパッド入力を扱う。CのポインタやSDLのエラー文字列はこの境界を越えない。

フロントエンドはCoreを一定サイクル進め、RGBAフレームバッファと入力ビット列だけをプラットフォーム層との間で交換する。将来はここにPCMを加える。コアの決定性を維持するため、CPU、PPU、APU、DMA、タイマを個別のfiberに分割しない。
