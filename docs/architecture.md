# アーキテクチャ

`Swanium::Core` はエミュレーション状態を保持し、同期的な `run_cycles` を公開する。ここには SDL2、OS API、ファイル I/O、壁時計を持ち込まない。

`Swanium::Platform` は OS 依存の実装を隔離する。現時点の `Swanium::Platform::Sdl` は、SDL2 初期化とウィンドウの安全な生成・破棄だけを公開する。C のポインタや SDL のエラー文字列はこの境界を越えない。

将来のフロントエンドは Core を一定サイクル進め、フレームバッファ、PCM、入力状態だけをプラットフォーム層との間で交換する。コアの決定性を維持するため、CPU、PPU、APU、DMA、タイマを個別の fiber に分割しない。
