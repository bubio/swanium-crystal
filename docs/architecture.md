# アーキテクチャ

最初の製品対象は macOS である。`Swanium::Platform` は将来の移植を妨げない境界として保つが、macOS の市販ゲーム互換性が安定するまで、ほかの OS 向け実装・配布・CI は追加しない。

`Swanium::Core` はエミュレーション状態を保持し、同期的な実行APIを公開する。`Machine` はCPU、LCDの159走査線タイミング、APUを同じ機械クロックで進める。`Ppu` は224×144のRGB444内部画面と固定長のRGBA8888フレームバッファAPI、`Apu` は24 kHz・16 bitステレオPCMを提供する。`SaveState` は機械状態をバージョン付きバイト列へ変換するだけで、ここには SDL2、OS API、ファイル I/O、壁時計を持ち込まない。

`Swanium::Platform` は OS 依存の実装を隔離する。`Swanium::Platform::Sdl` はSDL2初期化、ウィンドウ、ストリーミングテクスチャ、整数倍率表示、60 Hz提示、キーボード／ゲームパッド入力、音声キューを扱う。`StateStore`だけが専用設定ディレクトリのファイルを読み書きする。CのポインタやSDLのエラー文字列はこの境界を越えない。

フロントエンドはCoreを一定サイクル進め、RGBAフレームバッファ、入力ビット列、PCMをプラットフォーム層との間で交換する。`Frontend::Debugger`は実行制御とRGBAオーバーレイ描画を担当する。ローカル ROM はフロントエンドの明示的なファイル指定から `ProgramSource` に渡し、コアはパス、ファイル I/O、OS API を保持しない。コアの決定性を維持するため、CPU、PPU、APU、DMA、タイマを個別のfiberに分割しない。
